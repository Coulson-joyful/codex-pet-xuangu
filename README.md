# Codex Pet: 玄骨

用于 Codex 的 v2 动态宠物包。

## 内容

- `assets/spritesheet.webp`：11 行、8 列的 v2 精灵图集。
- `pet.json`：宠物清单，含 `spriteVersionNumber: 2`。
- `qa/`：图集和透明边缘验证报告，以及视线方向质检图。
- `玄骨宠物.md`：角色、动作与验证说明。

## 安装

将 `pet.json` 与 `assets/spritesheet.webp` 复制到 `~/.codex/pets/xuangu/`，并将精灵图重命名为 `spritesheet.webp`。
